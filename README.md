# 🧮 Windows Style Calculator

A simple and beginner-friendly **Windows Style Calculator** built with **Python** and **Tkinter**. It provides a clean graphical interface for performing basic arithmetic operations, making it an excellent project for learning Python GUI development.

## ✨ Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Simple and intuitive interface
* Clear (C) button
* Instant calculation
* Error handling for invalid input and division by zero

## 🛠️ Built With

* Python 3
* Tkinter (Python's built-in GUI library)

## 🚀 Getting Started

### Prerequisites

* Python 3.x installed on your computer

### Installation

1. Clone this repository:

   ```
   git clone https://github.com/your-username/windows-style-calculator.git
   ```
2. Navigate to the project folder:

   ```
   cd windows-style-calculator
   ```
3. Run the application:

   ```
   python calculator.py
   ```
